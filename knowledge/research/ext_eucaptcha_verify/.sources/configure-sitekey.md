EU CAPTCHA Protection switch: with Off, the widget does not set a challenge, and the requests continue without a verification. Default On.

Warning: with Off, there is no protection. The widget stays embedded. The requests are not examined.

This page does not print `/verify` JSON (`success` / `train`).
