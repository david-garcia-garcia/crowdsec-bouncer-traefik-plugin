Four types listed: reCAPTCHA v3, reCAPTCHA v2 ("I'm not a robot" Checkbox), reCAPTCHA v2 (Invisible reCAPTCHA badge), and reCAPTCHA v2 (Android).

Checkbox: user clicks a checkbox. Simplest option; two lines of HTML to render.

Invisible: no checkbox click. Invoked when the user clicks an existing button or via a JavaScript API call. The integration requires a JavaScript callback when reCAPTCHA verification is complete.

This page does not mention `g-recaptcha-response` or form fields.
