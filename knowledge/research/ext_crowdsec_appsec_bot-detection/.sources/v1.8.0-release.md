Published 2026-08-31. First stable engine release with WAF bot detection (New Features: Waf challenge mode #4268).

If enabled, clients are served a challenge + fingerprinting page; CrowdSec evaluates challenge and fingerprint. Docs link: https://docs.crowdsec.net/docs/next/appsec/bot_detection/intro

Also k8s datasource, HTTP helpers, LAPI stream performance. Security: two DoS fixes in HTTP and k8s-audit datasources.

Not a later 1.8.x for first ship of the feature. GitHub also listed v1.8.0-rc1 / rc2 before this tag, and v1.8.1 after.
