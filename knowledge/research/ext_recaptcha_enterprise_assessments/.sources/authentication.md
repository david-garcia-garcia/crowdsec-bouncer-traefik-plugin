API keys associate a call with a project for billing and quota without determining caller identity. They can be used only with methods that support API keys.

Fraud Defense supports API keys for `projects.assessments.create` (also annotate, some related-account and firewall-policy list methods).

For general API-key usage, this page points to Authenticate using API keys.

This page does not show `X-Goog-Api-Key` or `?key=` syntax. Last updated 2026-09-18 UTC on fetch.
