Google's API platform pre-defines system parameters available across all Google REST APIs and gRPC APIs. A system parameter can be specified as an HTTP query parameter or an HTTP header.

Table row for the API key:

- URL query parameter: `$key`, `key`
- HTTP/gRPC header: `X-Goog-Api-Key`
- Description: Google API key. See https://cloud.google.com/docs/authentication/api-keys
